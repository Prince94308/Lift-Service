# AuraLift | Premium Elevator & Lift Services Marketing Website

A modern, responsive marketing website for a professional Lift & Elevator Installation, Repair and Maintenance Company built with **React**, **Tailwind CSS**, **Framer Motion**, and **Lucide React Icons**.

## 🌟 Features

- **12 Full Marketing Pages**:
  1. Home (Hero, Company Intro, Services, Why Choose Us, Working Process, Industries, Featured Projects, Testimonials Carousel, FAQ Accordion, Contact CTA, Footer)
  2. About Us
  3. Services Overview
  4. New Lift Installation
  5. Lift Repair & Diagnostics
  6. Annual Maintenance Contracts (AMC)
  7. Elevator Modernization
  8. 24/7 Emergency Breakdown Services
  9. Projects & Portfolio Gallery
  10. Industries We Serve
  11. Contact Us
  12. Request a Quote
- **High-Converting Marketing Tools**:
  - Direct Click-to-Call buttons (`tel:`)
  - WhatsApp chat integration
  - Interactive Quote Estimator with client-side validation & demo mode feedback
  - Contact Form with client-side validation & instant feedback
  - Testimonials Carousel with auto-advance and manual controls
  - FAQ Accordion with smooth transitions
  - Floating 24/7 Breakdown & WhatsApp action pills
  - Floating Scroll-to-Top button
- **Responsive Across All Screen Sizes**:
  - Mobile (320px - 480px)
  - Tablets (640px - 1024px)
  - Laptops (1280px - 1440px)
  - Desktops (1536px+)
- **SEO & Performance**:
  - Full Open Graph & Twitter card metadata
  - Semantic HTML landmarks
  - `sitemap.xml` & `robots.txt`

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React Icons**
- **Framer Motion**
- **React Router DOM**

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Prince94308/Lift-Service.git

# Navigate into project directory
cd Lift-Service

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
